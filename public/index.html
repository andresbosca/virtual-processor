📝 Legenda:

          
    
            
  • X, Y: Registradores (0-3) → R0, R1, R2, R3
    • 
            
  • n: Valor imediato de 8 bits (0-255)
    • 
            
  • nn: Valor imediato de 8 bits (0-255)
    • 
            
  • a, aa: Endereço de 8 bits (0-255)
    • 
            
  • aaa: Endereço de 12 bits (0-4095)
    • 
            
  • 0: Bits não utilizados (sempre 0)
    • 
          


          
🚩 Flags Afetadas:

          
    
            
  • Zero: Resultado é zero
    • 
            
  • Negative: Resultado é negativo
    • 
            
  • Carry: Overflow em operações de adição
    • 
            
  • 
              Overflow: Resultado excede capacidade do
              registrador
            
    •

  • 
              ROM: 0x0000 - 0x7FFF (32KB) - Somente leitura
            
    • 
            
  • 
              RAM: 0x8000 - 0xFFFF (32KB) - Leitura/Escrita
            
    • 
            
  • Stack: Cresce de 0xFFFE para baixo
